Cinephage

Jellyfin bridge

Jellyfin plays the media. Cinephage decides what belongs in the library, files it and writes the shortcuts. This plugin is the bridge between the two.

  • Music stream shortcuts Active

    Stream-backed albums play in Jellyfin with duration, seek and progress on the first play.

  • More Cinephage features

    Future integrations arrive through this same plugin and update automatically.

Install and update this plugin from Cinephage → Settings → Integrations → Media Servers. Cinephage registers itself as a plugin repository, so there is nothing to add here by hand.
